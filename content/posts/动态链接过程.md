### Stack balance

**Stack balance** means managing stack space correctly during program execution. Its main purpose is to keep the stack pointer, such as `ESP`, **consistent** across function calls, avoiding crashes or vulnerabilities caused by incorrect stack management. It is central to calling conventions and program stability.

### Calling conventions

- **`cdecl`** (the default C calling convention in this setting):
  - The caller cleans up the stack space occupied by arguments.
  - For example, after `call func`, `add esp, N` restores stack balance.
- **`stdcall`** (commonly used by the Windows API):
  - The callee cleans up arguments when returning with `ret N`.
- **`fastcall`**: some arguments are passed in registers to reduce stack operations.

### Maintaining stack balance

#### Saving EBP

push ebp         ; Save the caller's EBP
mov ebp, esp     ; Record the current stack frame base in EBP

#### Restoring the stack pointer

mov esp, ebp     ; Release space occupied by local variables
pop ebp          ; Restore the caller's EBP
ret              ; Return; argument cleanup depends on the calling convention
