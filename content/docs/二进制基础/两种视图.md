## Linking view

This view consists of **sections** such as **.text, .data, .bss, .rodata, .symtab, and .strtab**.

These sections are used during linking to resolve symbols, relocate code, and perform related tasks.

At runtime, the loader uses segments rather than sections directly.

## Execution view

Common **segments** include:

- **LOAD**: a segment loaded into memory, containing code (R-X) or data (RW-).
- **DYNAMIC**: information used for dynamic linking.
- **INTERP**: the path to the dynamic linker, such as `/lib/ld-linux.so.2`.
- **NOTE**: additional program information, such as the ABI version.

## The compilation pipeline

### Preprocessing

1. Process **`#include`** directives and insert header contents.
2. Expand **`#define`** macros through textual substitution.
3. Process conditional compilation directives such as **`#ifdef` / `#ifndef`**.
4. Remove **comments** (`//` or `/* ... */`).
5. Produce **preprocessed source code** without preprocessing directives.

```c
gcc -E main.c -o main.i
```

### Compilation

1. Translate preprocessed C code (`main.i`) into **assembly code**.
2. Parse the code to check its syntax.
3. Perform lexical analysis to convert source text into tokens.
4. Perform semantic analysis to check variable scope, type compatibility, and related constraints.
5. Generate **optimized assembly code**.

```c
gcc -S main.i -o main.s
```

### Assembly

1. Translate assembly code (`.s` files) into **machine instructions in an object file**.
2. Produce a **binary `.o` object file**, which **cannot yet run independently**.

```c
gcc -c main.s -o main.o
```

### Linking

1. **Combine object files** (`.o` files).
2. Resolve **external symbols**, such as `printf` from `libc`.
3. Link **static libraries (`\*.a`) or shared libraries (`\*.so`)**.
4. Produce the final **executable**.

```c
gcc main.o -o main
```

> **Static linking** embeds library code in the executable, producing a larger file that does not depend on those external libraries at runtime.
>
> **Dynamic linking** loads `.so` files such as `libc.so` at runtime, producing a smaller executable that depends on external libraries.
